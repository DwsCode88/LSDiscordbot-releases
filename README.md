# LoneStar Bot — Windows releases

Installers for the LoneStar Card Shop Discord bot's Windows control panel.

**Download:** grab `LoneStarBot-Setup-x.y.z.exe` from the
[latest release](https://github.com/DwsCode88/LSDiscordbot-releases/releases/latest).
Installed copies update themselves from here.

The source code is private; this repo only holds the release files.
Releases are published automatically by the build pipeline, so there's
nothing to edit here.
